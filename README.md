## 📖 Detailed Subject Breakdown

### 1. Data Structures (DS)
- **Unit Coverage**: Covers Units 1 through 5 (Arrays, Searching, Sorting, Stacks, Queues, Linked Lists, Trees, Graphs, and Hashing).
- **Sub-folders**:
  - `BOOKS_DS/`: Modular textbook references for Units 1 to 5.
  - `NOTES_DS/`: Comprehensive printed notes, consolidated 2024 notes, plus unit-wise modules from MET Nashik and DY Patil College of Engineering.
  - `DS_QB/`: Assignment sheets (Assignments 1–5) and question banks from PVG and MET.
  - `VIVA_DS/`: `Data_Structures_Viva_Question_Bank.pdf` for practical and oral exam preparation.

### 2. Operating Systems (OS)
- **Unit Coverage**:
  - Unit 1: Introduction to Operating System Concepts & Architectures
  - Unit 2: Process & Thread Management, CPU Scheduling
  - Unit 3: Inter-process Communication (IPC) & Deadlocks
  - Unit 4: Memory Management & Virtual Memory
  - Unit 5: File Systems & Storage/Disk Management
- **Sub-folders**:
  - `NOTES_OS/HANDWRITTEN/`: Detailed handwritten notes covering Units 1 to 5.
  - `NOTES_OS/PPT_DYP/`: Lecture slide decks from DYPCOE.
  - `QB_OS/`: Includes `OS_Question_Bank_SPPU_2024_Table_Format.pdf` tailored to SPPU marking schemes and college compilations (SB Patil).

### 3. Object Oriented Programming & Computer Graphics (OOP / OOPCG)
- **Concepts**: Core OOP principles (Inheritance, Polymorphism, Encapsulation, Abstraction), Java/C++ implementations, Exception Handling, File I/O, and introductory Graphics algorithms.
- **Sub-folders**:
  - `NOTES_OOP/`: Unit notes 1 through 5, including specialized sets from SB Patil.
  - `QuestionBank/`: Dedicated OOP and CG question banks.
  - `Solution_QB/`: Full solutions for programming assignments (e.g., Java Programming).
  - `VIVA/`: Oral examination question banks with answers for lab exams.

### 4. Digital Logic and Electronic Design (DLED / DELD)
- **Concepts**: Number systems, Boolean algebra, Combinational logic circuits, Sequential circuits (Flip-Flops, Registers, Counters), ASM, and PLDs.
- **Sub-folders**:
  - `NOTES_DLED/Handwritten/`: Unit 1 through Unit 5 handwritten guides.
  - `NOTES_DLED/PVG/`: College lecture notes for Units 1 & 2.
  - `QB_DLED/`: Extensive question bank sets curated by SKN, PVG, and others.

### 5. Computer Graphics (CGRAP)
- **Content**:
  - Unit III and Unit IV question banks and assignments covering 2D/3D transformations, clipping algorithms, curves, and rendering.

### 6. Digital Marketing (DM)
- **Content**:
  - `NOTES_DM/`: Notes covering foundational digital marketing principles, SEO, SEM, and social media marketing.
  - `PPR_DM/`: 30-mark practice question papers (Set B).
  - `QB_DM/`: Unit III & IV assignments.

### 7. Universal Human Values & Professional Ethics (UHV)
- **Content**:
  - Notes for Units 1 and 2 focusing on human values, harmony in self, family, society, and nature.
  - Assignments and sample evaluation papers.

### 8. Previous Year Question Papers (PYQs)
- Contains official question papers for SPPU:
  - `SE Comp 2024 Pat SEM 3 PYQ Papers`
  - `S.E. 2024 PAT Sem 3 All Branches PYQ papers`

## 🚀 How to Use This Repository

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/AtharvBorkar/SEM-III.git
   cd SEM-III
   ```
2. **Find Your Subject:** Navigate to the folder corresponding to your target subject (e.g., `cd DS` or `cd OS`).
3. **Exam Preparation:**
   - Review theory using the `NOTES_*` directories.
   - Test your understanding using the `QB_*` folders.
   - Benchmark with past exam patterns in the `QUESTION_PAPERS/` directory.
   - Prepare for lab practicals and orals using the `VIVA/` and `VIVA_*` guides.
